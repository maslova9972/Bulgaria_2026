# Business & Travel Bulgaria 2026

Две самостоятельные статические версии лендинга для GitHub Pages:

- `/` — «Черноморский модернистский атлас»;
- `/classic.html` — классическая прибрежная версия.

## Локальный запуск

```bash
npm install
npm run dev
```

Production-сборка:

```bash
npm run build
npm run preview
```

Vite использует относительный `base: './'`, поэтому обе страницы и локальные изображения работают внутри подпапки GitHub Pages.

## Публикация на GitHub Pages

1. Создайте пустой репозиторий на GitHub и загрузите проект в ветку `main`.
2. В настройках репозитория откройте **Settings → Pages**.
3. В поле **Source** выберите **GitHub Actions**.
4. Workflow `.github/workflows/pages.yml` соберёт `dist` и опубликует обе страницы автоматически.

Для ручной проверки перед push выполните `npm run check`.
